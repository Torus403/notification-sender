# React Native client SDK

It runs inside your customers' mobile apps to register devices and track opens.
- **Publishes to:** npm (`@notification-sender/react-native`)
- **Test:** `pnpm --filter @notification-sender/react-native typecheck`

Right now it only holds client configuration. Endpoint methods and models will be generated from `spec/openapi.json` as the API lands. The package is not published yet.
